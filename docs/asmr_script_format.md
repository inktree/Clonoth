# ASMR 台本格式（草案）

> ⚠️ **本项目是独立工程，不属于 Clonoth/Bot。**
> 本文档只是设计参考，**不要在 Clonoth 工作区里实现**台本解析、TTS 批处理、混音等任何工具链，也不要在 bot 节点里挂载相关能力。实现代码放在独立仓库/目录中。

> 状态：草案 v0.2
> 日期：2026-10-06

---

## 这个文档在讲什么（人话版）

做 ASMR 音频得先有**台本**——就像剧本，写着：什么时候说什么话、什么时候放什么音效、哪里停顿几秒。

这份文档就是**台本的写法说明**。核心就一句：**一行一句**，用括号写指令。

```
欢迎来到今晚的放松时间。     ← 一句台词
(pause 6)                     ← 停 6 秒
接下来请放松。(sfx 翻书)      ← 说话时叠翻书声

(sfx 采耳 3m)                 ← 铺 3 分钟采耳声
```

台本里只写「要什么声音」（翻书、采耳），**不用管素材文件叫什么名字**——那是后面找素材的环节去解决的。

---

## 为什么不用 YAML

| 维度 | YAML | 字幕式 |
|---|---|---|
| LLM 生成 | 缩进/引号/嵌套都要吃 token，容易生成错结构 | 一行一义，最省 token |
| 人类精修 | 要脑内展开层级 | 逐行可读，改一行就是改一行 |
| 与时间轴关系 | 需要额外字段表达顺序 | 行序天然就是时间序 |

---

## 格式

```text
# 雨夜图书馆
@preset whisper_cn
@seed 1234
@bed rain_light

欢迎来到今晚的放松时间。请找一个舒服的位置，把耳机戴好。
(pause 6)
接下来的时间里，你不需要思考什么，只要听着就好。(sfx page_turn @3.2)
慢慢地，你会觉得身体越来越沉。

(sfx ear_cleaning 3m)
(sfx breath_soft 3m)
(pause 10)

感觉怎么样？有没有舒服一点。
```

## 行类型

| 写法 | 作用 |
|---|---|
| `# 标题` | 节目标题 |
| `@key value` | 元信息 |
| 普通文本行 | 一句台词，**一行 = 一个 TTS 段** |
| `(pause N)` | 插入 N 秒静音，由拼接阶段实现 |
| `(sfx 描述)` | 单次触发 |
| `(sfx 描述 @N)` | 段内第 N 秒单次触发 |
| `(sfx 描述 时长)` | **持续触发**，如 `3m`、`90s` |
| `(sfx 描述 @N 时长 档位 声道)` | 完整形式，后四项可选、顺序固定 |
| `// 备注` | 人类注释，不参与生成 |

**为什么一行就是一段**：TTS 的切分点由标点决定，而停顿必须由拼接阶段插（引擎句间静音上限只有 2.0 秒）。一行一段，等于把「切分点」和「停顿点」都交回给写台本的人。

## 触发音写描述，不写素材名

台本层**不需要知道素材库长什么样**。写台本时只要描述想要什么声音：

```text
(sfx 翻书)
(sfx 耳边呼吸)
(sfx 玻璃轻碰)
```

描述可以是中文词组，也可以是英文标识符（`page_turn`），怎么顺手怎么写。

**匹配交给专职节点**：台本定稿后，由一个负责素材的节点扫描全部 `(sfx ...)`，按分类检索素材库——

- 找到 → 绑定具体素材（记下它的基准响度、时长）
- 找不到 → 标记「待补」，输出缺口清单

这样台本不被素材库绑架：素材换了、加了同类备选，台本一个字都不用改。

**三个好处**：

1. 写台本的 AI 自由发挥，不必先查素材表
2. 同类音效有多个备选，可择优
3. 缺什么一目了然，直接产出采购/生成清单

### 参数顺序

`(sfx 描述 [@秒] [时长] [档位] [声道])`

| 位置 | 写法 | 例 |
|---|---|---|
| 描述 | 自由词组 | `翻书`、`page_turn` |
| @秒 | `@` + 数字 | `@2.5` |
| 时长 | 数字 + `s`/`m` | `90s`、`3m` |
| 档位 | 小 / 中 / 大 | `大` |
| 声道 | L / R / C 等 | `L70` |

后四项都可不写；写了就按这个顺序。

```text
(sfx page_turn)
(sfx 耳语 @3.5 90s 大 L80)
```

## 段内触发（人声还在继续时叠音）

触发音**不写进送 TTS 的文本**——它是后处理阶段叠加上去的，所以不会打断语音、也不会被读出来。

位置用行内标记：

```text
慢慢地，你会觉得身体越来越沉。(sfx page_turn @2.5)
```

- `@2.5` = 本段起点后 2.5 秒
- 解析时整段 `(sfx ...)` 被剥离，剩下的纯文本送去合成，韵律不受影响

**为什么不靠换行切分**：实测引擎只按句末标点（`。！？!?….`）切，**逗号不切**。把一句话硬拆成两行 = 两个独立片段，拼接处语调会断。

**秒数怎么定**：

1. 写台本时按语速估——约 0.2 秒/字（300 字/分）
2. 首轮跑完 TTS 后，工具会输出每段实际时长，回头校准

所以 `@` 的数值不必一次写准，第二轮微调即可。

> ⚠️ 标记由台本工具解析剥离，**别直接把带标记的文本送进 TTS**，否则会被当正文念出来。

## 持续型触发音

说话占比通常只有 40–60%，剩下的大段时间基本都由触发音撑起来——这是 ASMR 的主体。

写法就是在单次标记后加时长：

```text
(sfx ear_cleaning 3m)
(sfx breath_soft 3m)
```

这两行会**同时开始**播放，持续 3 分钟。

### 时间轴模型：游标 + 独立轨

台本只描述**事件**，不描述等待关系。解析时维持一个游标 `t`：

| 写法 | 对游标的作用 |
|---|---|
| 人声行 | 从 `t` 起播，播完 `t` 前进该段实际时长 |
| `(pause N)` | `t` 前进 N 秒 |
| `(sfx foo 时长)` | 在 `t` 处**启动** foo，foo 自己播完，**`t` 不动** |

**触发音不阻塞后续文本**——它一旦启动就独立走自己的时间。要给触发音留出独奏时间，用 `(pause)`。

```text
(sfx ear_cleaning 4m)
(pause 15)
接下来我会稍微动一下。(sfx tapping @1.5)
```

- `t=0`：ear_cleaning 起播，铺 4 分钟
- `t=0 → 15`：纯触发音独奏
- `t=15`：人声进来，**此时 ear_cleaning 还在响**
- `t=16.5`：tapping 叠上去

人声和触发音是**两条独立轨**，各走各的，最后混在一起。这正是「触发音当背景、人声叠上来」的标准形态，不需要额外的并行语法。

**节目总长度** = max(游标终点, 所有触发音的结束时刻)。

### 时长格式

| 写法 | 含义 |
|---|---|
| `90` / `90s` | 90 秒 |
| `3m` | 3 分钟 |
| `1m30s` | 1 分 30 秒 |

### 素材循环

素材比要求时长短时，**自动循环填满**；循环点做交叉淡化，避免听到接缝。

### 和停顿的区别

```text
(sfx foo 30)      // 有声音的 30 秒
(pause 30)        // 纯安静的 30 秒
```

要留一段安静给余韵，用 `(pause)`（游标前进、无声）；要持续铺触发音，用带时长的 `(sfx)`（游标不动、后台响）。

## 元信息

| key | 说明 |
|---|---|
| `@preset` | 人声预设：`normal_cn` / `whisper_cn` / `normal_ja` / `whisper_ja` |
| `@seed` | 随机种子，保证可复现 |
| `@bed` | 环境音预设（可在段中出现，见下） |
| `@title` | 可选，节目标题 |

## 环境音预设（段落式）

`@bed` 不限于开头——它可以出现在任何位置，**遇到新标记就切换**：

```text
@bed room_quiet

（开场白……）

@bed rain_light
（雨声渐入……）

(sfx 翻书)

@bed library
（场景切到图书馆……）
```

从某个 `@bed` 起，环境音一直延续，直到下一个 `@bed` 出现或节目结束。

内置预设：

| 预设 | 内容 |
|---|---|
| `room_quiet` | 仅房间底噪 |
| `rain_light` | 底噪 + 小雨 |
| `rain_heavy` | 底噪 + 大雨 |
| `library` | 底噪 + 翻书 / 远处脚步 |
| `cafe` | 底噪 + 低语 |
| `night_outdoor` | 底噪 + 虫鸣 |

预设定义文件的内容（素材引用、各自音量、循环方式）**等实做时再定**——现在只需要知道它是「预设名 → 一组素材 + 音量 + 循环」这个结构。

切换时默认做 2–3 秒交叉淡化，避免突兀（这与「单个触发音不加淡入淡出」不冲突：那是素材自带起落，环境音切换是硬拼两段不同的底子）。

## 立体声

方位感是 ASMR 的核心体验之一。声道标记跟在参数末尾：

| 标记 | 含义 |
|---|---|
| `C` | 居中（默认） |
| `L` / `R` | 偏左 / 偏右 |
| `L70` / `R30` | 带强度（0 = 居中，100 = 完全偏一侧） |
| `LR` | 双耳展开 |

```text
(sfx 耳语 L)
(sfx 呼吸 R80)
(sfx 环境 LR)
```

人声行同样可以带声道标记（写在行末）。

**自动换边**：长时间单侧容易听觉疲劳。用全局设置：

```text
@pan_swap 150
```

表示每 150 秒，把未显式指定声道的音轨左右对调。显式写了 `L`/`R` 的不受影响。

## 与时间轴的关系

台本**不写绝对时间码**。处理顺序：

1. 按行解析出台词段与停顿
2. 逐段跑 TTS，拿到每段实际时长
3. 按顺序拼接，得到完整时间轴
4. 冻结时间轴后，把 `(sfx)` 指令落到具体时间点

因为 TTS 确定性（同 seed 逐字节一致），这条时间轴可复现——隔几天重跑结果也一样。

## `@N` 的建议值

工具分两轮给数：

| 轮次 | 给什么 | 精度 |
|---|---|---|
| 首轮（还在写台本） | 按字数估算：字数 × 0.2s | 约 ±10% |
| 合成后 | 每段的**实际时长与起止时刻** | 精确 |

首轮估算够写个大概位置；跑完一遍合成后，工具输出每段的真实时间轴，把 `@` 校准到精确值即可。因为合成确定性，校准一次永久有效。

> ⚠️ **没有字级时间戳**。引擎只给整段总时长，不给「第几个字在第几秒」。要做到字级对齐，得改引擎（从 duration predictor 导出中间量），当前不做。

## 音量：三层分离

不同素材天生响度差得远——一支铅笔声和一个雷声不可能同音量。所以绝对分贝值不能由台本写死。

| 层 | 干什么 | 时机 |
|---|---|---|
| 素材注册 | 每个素材测基准响度，**归一化拉平** | 素材入库时（一次性） |
| 台本 | 只写**相对档位** 小 / 中 / 大 | 写台本时 |
| 混音 | 相对基准做最终微调 | 后处理时 |

这样 `(sfx page_turn @2.5 大)` 的含义是「比该素材基准响度高**一档**」，具体分贝由素材表和后处理决定，台本无需关心。

> 档位的实际数值、以及基准响度按 LUFS 还是 RMS 归一，**等实做时用真素材测过再定**。

## 已定设计

- [x] **多轨独立**：触发音启动后不阻塞文本，人声与触发音各走各的（游标模型）
- [x] **`@N` 建议值**：首轮按字数估算，合成后给精确值校准
- [x] **不做默认淡入淡出**：ASMR 触发音素材本身多带自然起落，额外加反而怪（2026-10-06 定）
